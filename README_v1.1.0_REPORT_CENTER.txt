SPK Windows Native v1.1.0 — Pusat Laporan
===========================================

Penambahan:
- Tab Laporan & Analitik diperluas kepada Pusat Jana Laporan.
- 13 jenis laporan:
  1. Ringkasan & Analitik Kehadiran
  2. Kehadiran Terperinci
  3. Murid Tidak Hadir / Ponteng
  4. Murid Berisiko
  5. Kes Aktif / Pemantauan
  6. Kes Dipulihkan
  7. Hubungan Penjaga
  8. Lawatan Rumah
  9. Sesi Kaunseling
 10. Intervensi
 11. Eviden
 12. Senarai Murid
 13. Senarai Guru
- Penapis Tahun, Tempoh dan Kelas digunakan untuk laporan berkaitan.
- Eksport Word sebenar (.docx) melalui Open XML.
- Eksport PDF berbilang halaman untuk laporan panjang.
- Eksport CSV analitik lama dikekalkan.

Asas:
- v1.0.0 Activation Code
- SQLite local-first
- SyncUniqueFix
- Railway provisioning/sync
