SPK WINDOWS NATIVE v0.7.1 — SERVER CONFIG BUTTON

PEMBAIKAN
- Tambah butang "Import Server Config" terus pada halaman Sync Railway.
- Pengguna tidak perlu masuk Backup / Restore untuk memilih Server Config ZIP.
- Selepas import, aplikasi semak School ID config dengan SQLite lokal.
- Jika tidak sepadan, Sync disekat dan amaran dipaparkan.
- Jika sepadan, pengguna boleh tekan "Uji Server" kemudian "Sync Sekarang".

FORMAT CONFIG
ZIP mesti mengandungi server/server.json atau server.json.
Token disimpan menggunakan Windows DPAPI seperti v0.7.0.
