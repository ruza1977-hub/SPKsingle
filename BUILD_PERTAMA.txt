SPK Windows v0.1.3 — WinUI Official Build Configuration
=======================================================

PENTING: Extract terus ke C:\SPK013 (path pendek).

1. Tutup Visual Studio lama.
2. Padam folder bin dan obj jika ada.
3. Buka C:\SPK013\SPK_Windows.sln
4. Pastikan configuration: Debug | x64
5. Klik kanan solution -> Restore NuGet Packages.
6. Build -> Rebuild Solution.
7. JANGAN tekan F5 jika Rebuild belum menunjukkan "Build succeeded".
8. Selepas Build succeeded, F5.

Output yang dijangka:
C:\SPK013\SPK\bin\x64\Debug\net8.0-windows10.0.19041.0\win-x64\SistemPengurusanKehadiran.exe

Jika Rebuild gagal, screenshot Error List dan Output > Build diperlukan.
