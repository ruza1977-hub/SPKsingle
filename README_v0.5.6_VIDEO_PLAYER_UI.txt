SPK Windows Native v0.5.6 — VIDEO PLAYER UI
============================================

Perubahan hanya fokus pada reka bentuk UI Eviden Video:
- Lebar panel/player kiri dikurangkan kira-kira 3 cm (113 px pada 96 DPI): 500 -> 387.
- Tinggi minimum player ditambah kira-kira 2 cm (76 px pada 96 DPI): 650 -> 726.
- Footer di bawah player dibuang daripada paparan.
- Tulisan status cache di bawah player tidak lagi dipaparkan.
- Butang Stop Video dipindahkan ke panel kanan, bersama Carian / Tambah / Main.
- Fungsi cache, WebView2, MediaPlayerElement dan database tidak diubah.
- Standard backup/database Mac daripada v0.5.5 dikekalkan.

Nota: CacheStatus masih wujud sebagai elemen tersembunyi untuk mengekalkan keserasian code-behind.
