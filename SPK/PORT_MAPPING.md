# Pemetaan Final macOS → Windows v0.1

| Final macOS | Windows v0.1 |
|---|---|
| SwiftUI NavigationSplitView | WinUI 3 NavigationView |
| SQLite3 C API | Microsoft.Data.Sqlite |
| Application Support | %LOCALAPPDATA% |
| Private token file | Windows DPAPI CurrentUser |
| Universal ZIP importer | Universal ZIP importer C# |
| Railway sync v1 | Railway sync v1 C# |
| PDFKit / AVKit / WebKit | akan dipindah ke Windows PDF/WebView2/MediaPlayer pada fasa media |

Skema SQLite sengaja disamakan supaya kedua-dua klien menghantar payload Railway dengan table/field yang sama.
